# WSL 管理器

这是一个 WSL 管理器 GUI 软件。

需要达成以下目的：

- 能查看 WSL 容器列表，对容器进行基本操作，例如启动、停止
- 能查看运行中的 WSL 实例以及其状态，对状态进行统计
- 实现 WSL 的保活，受限于传统保活机制需要使用命令行不停运行命令，该软件需要有多种保活机制以提供对 Host 最小影响，使 WSL 能作为服务使用。同时提供对保活的设置及管理，对于第二条要有保活状态的统计

必要时可以配合容器内部的应用和服务来里应外合。

## 技术栈要求

- .Net 10/C#
- Avalonia 12/Huskui.Avalonia

其他技术自选，只要能达成目的即可。
